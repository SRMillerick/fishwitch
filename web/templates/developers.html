anonymous JSON · CORS · free with attribution

The short version: the same deterministic ranking the site serves is available as anonymous JSON. No key, no account, CORS open, attribution to baromoon.com required.

API v1

  • GET /api/v1/report — a scored session report for one water.
    Params: lake (registry id, see /lakes), at (YYYY-MM-DD HH:MM), hours (0.5–8, default 2.5), species, voice (fisher/almanac/astro), bottom (grass/muck/sand/rock/wood), clarity (clear/stained). Rate limit 60/hour per IP; cached 5 minutes.
  • GET /api/v1/windows — a 1–16-day horizon scan (default 7 days). Rate limit 120/hour per IP; cached 15 minutes.

Every response carries an envelope: api, generated_at, source, license, disclaimer. Every pick keeps its cited source, and the disclaimer is part of the contract. Live example: /api/v1/windows?lake=hidden-valley-lake-ca&days=3.

Embed the ledger

The same windows can be embedded on any page with an iframe:

<iframe src="https://baromoon.com/embed/ledger?lake=hidden-valley-lake-ca&days=7"
        width="420" height="360" loading="lazy"
        title="baromoon windows"></iframe>

Optional params: days (1–16), species. The widget carries its own attribution, and the embed page is marked noindex on our side so it never competes with your page.

Feeds

  • /ledger.ics — subscribable calendar of the A/S windows (lake, days).
  • /outlook.rss — RSS of the same windows.

Attribution & limits

Free to use with attribution to baromoon.com. Conditions are estimates (a forecast, an inferred lake state, and an air-temp water model unless a gauge is live) — a plan, not a promise. Be gentle with the rate limits; they exist so the VPS stays fast for everyone, and the API is not a bulk-download endpoint.
