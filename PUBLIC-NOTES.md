# Public mirror

Clean public mirror of fishwitch — mirrored from the private development
ledger by `publish-mirror` (mirror of archive@2425099). Excluded from the
mirror: session docs, generated reports, and home-lake intel. Profiles and
logbooks are gitignored by policy in both repos (identity-grade PII).

Rendered showcase: GitHub Pages (gh-pages branch), built by `build_static.py`
(anonymous snapshots only — no profiles, no natal data, no logbook data).
