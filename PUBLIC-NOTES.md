# Public mirror

This is the clean public mirror of fishwitch. The private development ledger
(`fishwitch-archive`) additionally holds session docs, generated reports, and
the author's home-lake intel — none of it is personal data of any other
angler: profiles and logbooks are gitignored by policy in both repos.

Rendered showcase: GitHub Pages (gh-pages branch), built by `build_static.py`
(anonymous snapshots only — no profiles, no natal data, no logbook data).
